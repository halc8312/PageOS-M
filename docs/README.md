# Documentation Index

- `architecture/`: kernel, IPC, scheduler, VFS, memory, syscalls, and window-system design.
- `design/`: retro-modern UI, color palette, and responsive behavior.
- `specs/`: curated reference matrix, fetch script, and local-only spec placeholders.
- `tasks/`: phase-by-phase execution plan from foundation through polish.
- `conventions/`: Rust, TypeScript, git, and testing conventions.

When requirements were ambiguous in Phase 0, the project chose the simplest browser-safe implementation that preserves the microkernel boundary and records the decision in the relevant document.
