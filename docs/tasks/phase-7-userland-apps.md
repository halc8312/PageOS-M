# Phase 7 Userland Apps

## 概要
shell、editor、filemgr、sysmon、settings、calc を実用最小限まで育てる。

## マイルストーン
### M-7.1 基本アプリ
- [ ] shell/terminal を接続してコマンド実行を可能にする
- [ ] calc と settings の UI/状態保存を完成させる
- [ ] sysmon で process / memory / IPC を表示する

### M-7.2 生産性アプリ
- [ ] editor のテキスト編集と保存を完成させる
- [ ] filemgr の一覧・作成・削除・移動を実装する
- [ ] アプリアイコンとメタデータ管理を整える

## 完了条件
- 主要アプリが shell 上で連携する
- デモ用途の OS 体験が成立する

## テスト要求
- アプリ統合 E2E テスト
- 永続設定テスト
