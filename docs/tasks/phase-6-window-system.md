# Phase 6 Window System

## 概要
ウィンドウサーバーとコンポジタのコマンドプロトコルを整備し、レイアウト機能を拡張する。

## マイルストーン
### M-6.1 プロトコル
- [ ] window create/update/destroy コマンドを型で固定する（参照: `docs/architecture/window-system.md`）
- [ ] 入力フォーカスと z-order をサーバー主導にする
- [ ] compositor 側差分描画を最適化する

### M-6.2 UX 拡張
- [ ] タイル/スナップ配置を追加する
- [ ] モバイルのアプリスイッチャーを追加する
- [ ] テーマ設定の反映をリアルタイム化する

## 完了条件
- 主要 UI 操作が kernel/server の状態と同期する
- デスクトップ/モバイル両方で複数アプリ遷移が成立する

## テスト要求
- ウィンドウ操作 E2E テスト
- 描画コマンドの単体テスト
