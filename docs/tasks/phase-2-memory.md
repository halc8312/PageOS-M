# Phase 2 Memory

## 概要
仮想メモリ概念、ヒープ統計、アドレス空間メタデータを段階的に導入する。

## マイルストーン
### M-2.1 メモリ記述子
- [ ] プロセスごとのメモリ記述子を追加する（参照: `docs/architecture/memory.md`）
- [ ] 共有/専有バッファ区分を定義する
- [ ] ヒープ統計を公開する

### M-2.2 保護モデル
